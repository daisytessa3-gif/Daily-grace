DAILY GRACE — INSTALLABLE MINI APP

WHAT'S INCLUDED
- Daily rotating scripture and prayer
- Save favourite prayers
- Copy prayers
- Offline caching after first successful visit
- Reminder time setting and browser notifications while the app is open

IMPORTANT ABOUT INSTALLATION
This folder is a Progressive Web App (PWA). Android Chrome can install it from a secure HTTPS website.
A local HTML file cannot be installed as a full PWA. Upload these files to an HTTPS static host (for example, Netlify or GitHub Pages), then visit the site in Chrome on your phone and choose Install app / Add to Home screen.

NOTIFICATION LIMITATION
The reminder in this starter app checks while the app page is open. Reliable scheduled notifications while the app is completely closed need a push-notification backend/service or a native Android app. This bundle does not pretend to provide that background service.

FILES
- index.html: app interface and prayer content
- manifest.webmanifest: install metadata
- sw.js: offline cache and notification click handling
- icon.svg: app icon
